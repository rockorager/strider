Themes from Omarchy (https://github.com/omacom/omarchy, `themes/`), their
`colors.toml` copied unchanged, which `crates/strider/src/theme.rs` maps to
Strider's colors. The `omarchy-tokyo-night` and `omarchy-catppuccin-latte`
scenes (`crates/strider/src/scenes.rs`) show the columns under them.
